# Data Sources

All invoices in this directory (`INV-2024-001.pdf` through `INV-2024-005.pdf`) are
**fully synthetic**. They contain no real company names, real addresses, real
registration numbers, or real personal information.

## Generation

Generated by `generate_invoices.py` using:
- **reportlab 4.x** for PDF layout and text embedding
- **IPA Gothic** (ipagp.ttf) — a freely licensed Japanese TrueType font
- Designed for native-text extraction (pdfplumber, not OCR)

## Intentional inconsistencies for agent validation testing

| Invoice | Status | Issue |
|---------|--------|-------|
| INV-2024-001 | valid | — |
| INV-2024-002 | valid | — |
| INV-2024-003 | valid | — |
| INV-2024-004 | **invalid** | 消費税 stated as ¥30,000; correct value is ¥25,000 (10% of ¥250,000) |
| INV-2024-005 | **invalid** | 合計 stated as ¥650,000; correct value is ¥660,000 (¥600,000 + ¥60,000) |
